# Upstream provenance

This crate is an OxyViewer-owned, image-metadata-only fork of
[TrueSpar SiftX](https://github.com/truespar/siftx) at commit
`fcf8e3d37213b3449c7293930f6a886495767673`.

The original project is licensed under MIT OR Apache-2.0. Its `LICENSE`,
`LICENSE-MIT`, and `LICENSE-APACHE` files are retained in this directory.

The PDF, GUI, command-line, FFI, and language-binding code is intentionally
excluded. OxyViewer owns the public integration API and carries focused
extensions for camera metadata that are required by the application.
