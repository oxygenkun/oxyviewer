# Architecture Decision Records

ADRs record durable architectural decisions and their tradeoffs. Their numbers
are stable; gaps mean an earlier proposal was removed or never accepted and
should not be renumbered.

| ADR | Decision |
| --- | --- |
| [0001](0001-no-blocking-import.md) | Opening a folder must not perform a blocking import |
| [0004](0004-heif-full-resolution-sessions.md) | HEIF full-resolution decode sessions |
| [0005](0005-unified-preview-pipeline.md) | Unified preview pipeline across formats |
| [0006](0006-semantic-render-level-graph.md) | Semantic render-level graph |
| [0007](0007-optional-exiftool-capability.md) | Optional ExifTool metadata capability |
| [0008](0008-rust-owned-resource-projections.md) | Rust-owned versioned resource projections |
| [0009](0009-scoped-multilevel-work-scheduling.md) | Scoped multi-level work scheduling |
| [0010](0010-explicit-release-check.md) | Explicit-only release check in the About panel |
| [0011](0011-first-party-analyzer-host.md) | First-party analyzer host and portable human face facts |

Implementation status belongs in the roadmap or an active task plan; dated
validation evidence belongs under `docs/research`.
