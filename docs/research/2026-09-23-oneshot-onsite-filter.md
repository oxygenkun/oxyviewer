# 无历史图库的 one-shot 现场人物过滤验证

2026-09-23。在 E0/E1 冻结快照和特征上做逐照片查询。此处 one-shot 指用户在当前批次
选定**一张**有人脸的人物照片，默认以这一个人脸向量过滤批次中其他已拍照片；另测体貌回退。
不用已命名身份图库、
人工真值建立原型或后期全池传播。分数和身份真值只用于离线调阈值与评分，不进入过滤器。
本实验复用 E0/E1 的 test，而该 test 已在此前研究被观察，因此均为探索性诊断。

## 协议和分母

- 仅纳入用途初审 A、人工脸框标注为正脸或侧脸且未标为模糊、**人体框标注为清晰正面或侧面**
  的实例。人体模糊、遮挡、背对及无足够人体标注确认是否合格的实例均从查询和候选池排除；
  人脸模糊也排除。不能仅凭检测器是否成功来挑样本。初审尚未由用户再次确认。
  calibration 50 个已知查询，validation 29 个，test 30 个；test 为清晰正脸 15、侧脸 15。
  与上一版较宽的 A 类口径相比，另排除 calibration 的 1 个背对人体和 validation 的
  2 个缺人体标注实例；此前已有 1 个模糊脸及 1 个脸姿态缺失被排除。
- 每个已知实例轮流作为唯一查询；候选为**同一划分**的其余合格实例，同照片排除。
  这模拟选定一张照片后过滤已在当前批次中的照片，不模拟未来照片的在线到达。
  同一人物出现两张照片，产生两个有向查询结果；这是按“每张都可能被用户选中”计数，
  不能将有向配对数说成人数。未知候选保留为非同人；未知查询未计入。
- 自动框路线含人体检测、脸与人体关联及匹配人工实例的现有 E0/E1 向量；关联失败仍留在分母。
  人工框辅助路线是有标注几何时的上界，不是可直接部署的自动结果。
- 每个编码器独立从 calibration 的 0.20–0.90、步长 0.025 阈值中，先保留零观测误返回的阈值，
  再取同人返回最多者。另展示 validation 重新校准到零观测误返回的阈值在 test 上的结果。
  test 不参与阈值计算，但此前研究已观察过它，不能称为独立验收。
- 主指标为同人有向配对召回 TP/全部正配对、返回精度 TP/(TP+FP)、异人返回 FP；
  查询或候选缺所需特征时，正配对仍留在分母。没有完整端到端耗时测量。

## 自动框对照

所有模型 test 的分母均为 396 个同人有向配对、474 个异人有向配对；
validation 为 350 个同人、462 个异人配对。

| 编码器 | calibration 阈值 | validation 同人返回 /350、误返回 | test 同人返回 /396、误返回 | validation 重校阈值 | test 重校后同人返回 /396、误返回 |
| --- | ---: | ---: | ---: | ---: | ---: |
| ArcFace | 0.325 | 172、46 | 356、136 | 0.425 | 328、6 |
| AdaFace | 0.400 | 168、12 | 360、18 | 0.475 | **348、0** |
| LVFace-T | 0.325 | 142、16 | 308、28 | 0.425 | 276、0 |
| LVFace-S | 0.275 | 168、2 | 290、20 | 0.300 | 288、10 |

calibration 的零误阈值没有稳定迁移到 validation。test 上 AdaFace 0.400 返回精度
为 360/378=95.2%，同人配对召回 360/396=90.9%；不能只报其召回。
validation 重校后的 AdaFace 0.475 在 test 为 348/396=87.9% 同人配对召回、
474 个异人配对中观测零误返回。这一配置比其他重校模型保留更多同人配对，
可作为下一次独立场次实验的**候选配置**，不是线上低误认率结论。

## 现场优先召回的重新选择

现场候选列表允许人工剔除错图，因此将“准确率”具体解释为**返回精度**，并改为先满足
尽可能多的同人照片进入候选列表。可达上限只由**现有脸特征是否可用**决定：自动框在
calibration 最多 920/956、validation 最多 182/350、test 最多 366/396 个同人有向配对；
继续降低余弦阈值也不能取回没有脸向量的照片。validation 的缺特征查询为 8/29，
test 为 2/30，因此不同划分的原始召回不能只归因于模型或阈值。

本次补充分析按 calibration 和 validation 的标签选择：在列举的阈值中，保留两者**所有有特征
的同人配对**，取其中最高阈值。四模型自动框对照如下；test 仅作探索性核对：

| 模型 | 选定阈值 | validation 同人返回、错候选、精度 | test 同人返回、错候选、精度 |
| --- | ---: | ---: | ---: |
| ArcFace | 0.250 | 182/350、78、70.0% | 364/396、288、55.8% |
| **AdaFace** | **0.300** | **182/350、62、74.6%** | **366/396、144、71.8%** |
| LVFace-T | 0.000 | 182/350、212、46.2% | 366/396、390、48.4% |
| LVFace-S | 0.000 | 182/350、182、50.0% | 364/396、390、48.3% |

LVFace-T/S 在 CPU 编码器计时更快，但在这个**高召回 one-shot**选择规则下，
需要返回更多异人候选，不能据此替换 AdaFace；编码器耗时也不是完整现场延迟。

### 体貌证据是否能补回缺脸

固定同一干净子集和相同的高召回阈值选择规则，额外比较 body-only、
AdaFace 与 OSNet 固定 70/30 融合且缺模态时单路回退、以及有脸时只用 AdaFace／
缺脸时才回退 OSNet。表中高召回仍在 calibration、validation 选择阈值。

| 自动框路线 | 阈值 | validation 同人召回、错候选、精度 | test 同人召回、错候选、精度 |
| --- | ---: | ---: | ---: |
| AdaFace 人脸 | 0.300 | 182/350、62、74.6% | 366/396、144、71.8% |
| OSNet 体貌 | 0.375 | 350/350、428、45.0% | 390/396、436、47.2% |
| AdaFace＋OSNet 70/30；缺模态回退 | 0.350 | **350/350**、276、55.9% | **396/396**、224、63.9% |
| AdaFace 优先；仅缺脸时用 OSNet | 0.300 | **350/350**、286、55.0% | **396/396**、228、63.5% |
| LVFace-T 优先；仅缺脸时用 OSNet | 0.000 | 350/350、436、44.5% | 396/396、474、45.5% |
| LVFace-S 优先；仅缺脸时用 OSNet | 0.000 | 350/350、406、46.3% | 394/396、474、45.4% |

两种混合方式在这批干净的同场次照片中都补回了缺脸造成的配对漏检；
固定 70/30 在该数据上仅比“缺脸才回退”少 10/4 个 validation/test 错候选配对，
不足以证明有脸时混入体貌具有稳定收益。test 的 29 个有同人照片的查询中，
混合方式 29 个均找齐，但 30 个查询全部带回错候选；70/30 的每次查询错候选
中位数 6.5 张、p95 约 14 张。体貌可能主要抓住同场服装，跨场次、换装及同服装异人
尚未验证。因此可以把它当作**高召回候选提示**，不能自动确认身份。

这些是每张合格照片轮流作查询产生的**有向配对**，不是 144 张互不相同的错图。
AdaFace 0.300 在 test 的 30 个查询中有 25 个至少返回一张错候选；每次查询错候选
中位数 4、p95 约 11.6 张，用户需要人工浏览和剔除。相对 0.475 的安全优先配置，
0.300 多取回 18 个同人有向配对，同时从 0 增至 144 个错候选配对。
29 个确有同人候选的 test 查询中，仅 13 个取回了**全部**同人照片；一个缺脸候选
会使多个查询无法找齐，配对召回 92.4% 不能解释为 92.4% 的查询已找齐。
若愿意略让出 calibration/validation 各 2 个可达同人配对，0.325 在 test 仍取回
366/396，但错候选为 96；这只是 test 上的诊断，不能据此反选 0.325。

**纯脸高召回基线为 AdaFace 0.300。** 产品应显示“可能是同一人”的可核对列表，
按相似度排序，不自动确认身份；对无脸特征及多脸歧义的照片设单独待查入口，
不能静默当作无此人。是否接受每次约数张错候选、跨场次能否保住相同召回，
都需独立场次和真实界面操作验证。

在 AdaFace 0.475 下，test 的同姿态正配对返回 218/240=90.8%，跨正／侧脸返回
130/156=83.3%。姿态跨越仍是主要漏检桶。自动框 test 有 2/30 个合格查询没有脸特征；
validation 为 8/29。test 的 DSC00907、DSC00964 各检测出两张脸、一个人体，现有
“唯一脸中心落在人体框内”规则各发生一次关联失败。人工框辅助的同阈值 test 为
374/396=94.4%、零观测异人返回；这给出几何／关联改进的潜在上界，不能归因于单一修复。

## 判断与下一轮

1. **先修现场脸入口和关联歧义。** 保留人脸级候选，让用户明确选中哪张脸；自动多脸关联
   需要独立验证，不能直接把人工框辅助结果算作修复收益。尤其 validation 的 8 个缺脸查询
   表明该问题不只出现在 test 的两张照片。
2. **优先召回时把 AdaFace + 0.300 和缺脸时体貌回退并列验证。** 0.475 保留为安全优先对照；
   用未见场次比较脸单路、体貌回退及 70/30 混合，记录每个查询的返回精度、
   同人召回、错候选照片数和人工筛选时间。
   现有样本同场次、仅少数身份；零观测错误不足以证明很低的真实误认率。
3. **跨姿态漏检先做单参考排序和灰区复核。** 不能用 test 上的配对结果反向选择新的阈值、
   query expansion 或多原型策略；one-shot 的第一张照片可能只有一种姿态，自动扩展又有
   假匹配污染风险。下一实验可预注册“高分直接返回、中间分数待确认、低分排除”的两阈值策略。
4. **测真实现场延迟。** 人脸检测、对齐、编码、当前批次检索及界面显示的 p50/p95
   尚未测量；现有 CPU/CUDA 编码器耗时不等于完整响应时间。
