# 现场 1 张与 3 张高质量参考照片对照

2026-09-23。承接[干净子集 one-shot 验证](2026-09-23-oneshot-onsite-filter.md)。
只使用当前批次、用途初审 A、人体清晰正/侧面且不遮挡、脸为非模糊正/侧面的实例。
三张参考须由用户确认同一人物；实验用现有身份真值模拟这一步人工选择，
真值不进入相似度或候选排序。人脸选取“高质量”按自动提取的检测分×脸尺寸×模糊度代理
排序，并非人工审美判断或可识别概率。只选有可用 AdaFace 特征的参考图。

## 公平比较方法与样本限制

- 每个身份选质量最高的 1 张或 3 张；另测 3 张中尽量包含质量最高的正脸和侧脸。
  三图分数比较 `max` 与最高两张分数的均值 `top2`。体貌回退仍遵循“有脸先用脸，
  缺脸才用 OSNet”，每张参考独立产生分数后再聚合。
- 同一身份所有配置共享**完全相同的候选池**：排除该身份质量前三张与姿态多样三张的并集。
  因而单图和三图的正、负样本分母一致；这也是比前一报告的逐图 one-shot
  更小的候选池，两个报告的配对数不能直接相减。
- 只比较至少有 3 张可用参考且参考以外仍有同人照片的身份。calibration 3 个身份，
  validation 2 个，test **2 个**；test 中另一身份仅有 1 张合格照片，无法参加。
  test 共 22 个待检同人实例，validation 20 个。
- 每种评分配置在 calibration/validation 上选尽量保留有特征同人配对的最高阈值；
  同时展示固定阈值 0.300 的诊断。test 在之前实验已被观察，以下只是探索性结果。
  选三张参考发生在同批照片已取得后；未测连续拍摄中参考图尚未到齐的时刻。

## 固定各配置阈值后的对照

下表“同人/分母；错候选”按每个人选定一次参考计数，错候选是不同人物的返回实例，
不是身份误认率；阈值各自在 calibration/validation 选择。

| 模型与参考选择 | 聚合 | 阈值 | validation | test |
| --- | --- | ---: | ---: | ---: |
| AdaFace，质量最高 1 张 | 单分数 | 0.400 | 12/20；0 | 21/22；1 |
| AdaFace，质量最高 3 张 | 最大值 | 0.450 | 12/20；0 | 21/22；0 |
| AdaFace，质量最高 3 张 | 最高两张均值 | 0.450 | 12/20；0 | 21/22；0 |
| AdaFace，正/侧脸兼顾 3 张 | 最高两张均值 | 0.550 | 12/20；0 | 21/22；0 |
| AdaFace＋缺脸体貌回退，质量最高 1 张 | 单分数 | 0.400 | **20/20；8** | **22/22；4** |
| AdaFace＋缺脸体貌回退，质量最高 3 张 | 最大值 | 0.450 | **20/20；8** | **22/22；3** |
| AdaFace＋缺脸体貌回退，正/侧脸兼顾 3 张 | 最高两张均值 | 0.550 | **20/20；6** | **22/22；1** |

三图没有在这两个 test 人物上多取回同人照片。纯脸仍漏 1 张，主要是候选缺脸特征；
体貌回退在本批补回它。三图阈值重校后有少量错候选下降，但不足以从两个查询推断
稳定优势。正/侧脸兼顾的三图 `max` 变体在 test 为 21/22、零错候选，
说明姿态覆盖与聚合规则要一起评估，不能只数参考张数。

**不能让三图沿用单图阈值。** 固定 0.300 时，AdaFace 纯脸在 test 的同人返回
三种配置均为 21/22，但质量前三张 `max` 的错候选由单图的 9 增至 17；
AdaFace＋体貌回退均为 22/22，错候选由 12 增至 20。
`max` 会让任何一张参考的偶然高分进入结果；三图需要重新校准阈值，
而 `top2` 的收益仍要在新场次验证。

## 当前判断

对于用户优先的**高召回**，先选 1 张确实清晰、能看到脸的照片，加缺脸体貌回退，
已在该 test 的可比候选池取回 22/22；三张目前没有证明能进一步增加召回。
如用户已手动确认三张同人照片，可使用三图候选排序，但要单独阈值，
并显示错候选供确认。后续至少要扩大身份、场次及正/侧脸组合，再决定是否默认要求三张。
