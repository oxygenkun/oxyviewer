# OxyViewer

[English](README.md) | **中文**

> OxyViewer 是一个实验性的、完全由 AI 构建的 Tauri 项目，目前仍处于预发布阶段。

![OxyViewer 应用界面](./docs/assets/image.png)

OxyViewer 是一款本地优先的桌面应用，致力于流畅浏览、检视和管理相片。

OxyViewer 采用 Tauri 2 构建桌面核心。它支持现代相片工作流，包括 RAW 、JPG 和 HEIF 预览、渐进式全细节查看、色彩管理、元数据筛选。
